Locator mapping Built-in

The mapping file has 4 columns: Substore Locator, I360 store name, Circle, SFX Store Name. Uploading one adds its rows to the built-in mapping (and corrects any locator it repeats) in this browser until you reset it — it never wipes the rest of the mapping.

How this works

  1. Step 1 — SS: each row's LocatorName is looked up in the locator mapping and the SFX store name is filled in as SS.
  2. Step 2 — Order Num: OrderNum NA becomes S2W Pendency; any other value (a number or S2W Raised) becomes S2W raised.
  3. Locators missing from the mapping, or mapping to more than one store, are left blank and listed above — never guessed.
  4. The download also carries a Pivot sheet — SS in rows, Order Num in columns, serial count in values — with the Pendency column in 3 red tones, darkest for the biggest count. The store table above shows the same pivot on screen.
  5. Values wrapped as ="..." in the export are unwrapped automatically. WMS_DUMMY placeholder serials are kept as-is.
