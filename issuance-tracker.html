What was applied to the raw file
  1. Zip extracted in memory; the sheet is streamed (never fully loaded) for speed.
  2. Only rows whose Substore_Locator contains SDFX are kept.
  3. Store (SFX Store Name) and Circle mapped from the locator table. Unmapped locators are shown as circle UNMAPPED and listed in a warning.
  4. Where Serial_Number is not blank, Issued_Qty = 1.
  5. Serial present: iptv first → then ONT (→ Ont) → Modem outdoor (→ W-Modem outdoor) → WiFi router (→ Wifi router). Serial blank: Cat 6 cable; item code B0IMPXV5 → Face Plate; monkey-bit cable / optical or drop fibre cable that is outdoor → Outdoor cable; Drop Fiber accessories kept.
  6. Txn_Date shown as dd-mmm and rolled up per day.
  7. Pivot: rows = Txn_Date, Circle, SS, Engineer_Name; columns = Cat 6, Drop Fiber accessories, Wifi router, W-Modem outdoor, Ont, Face Plate, Outdoor cable; values = Issued_Qty.
  8. Highlight (columns Cat 6 → Grand Total): red if Cat 6 > 20 m per Modem+WiFi set, or Face Plate / Drop Fiber > 1 per ONT, or Outdoor cable more than 90 m per ONT plus the 100 m tolerance; otherwise green.
  9. Excess Cat 6 and Excess out. Cable columns hold the quantity above the standard (Excel formulas in the download).
Assumptions to confirm
  • “ontx” was read as the pivot label Ont.
  • Face-plate item code is B0IMPXV5 (zero), matched case-insensitively and also if typed with the letter O.
  • Txn_Type defaults to Allocate (as in your existing pivot); tick Recover to include it.
  • Because rows are rolled up per day, a day's ONTs, face plates and cables for one engineer are checked together.
